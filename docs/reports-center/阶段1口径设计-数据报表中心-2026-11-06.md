## 一、已定口径（D2–D6 的精确定义）

### D2 消课收入：学员混合单价（估算口径，全站标注）

课包已弃用、消课无包级归属，单价只能按学员维度摊算：

- 学员实付总额 `paid_amount(s)` = 该学员 payments 中 payment_method != 'gift' 的 amount 之和（CNY）。
- 学员总课时 `total_hours(s)` = students.total_hours（计数器为累计购课时的权威值；payments.hours 是后加字段，早期数据可能不全，不作分母）。
- **混合单价 `blended_price(s)` = paid_amount(s) / total_hours(s)`**，total_hours 为 0 时无单价。
- 期间消课收入 = Σ（期间内 status='completed' 的 classes.hours × 该学员 blended_price）。classes.hours 已含 25 分钟课的 0.66 系数（完课时写入），**禁止再按 duration 二次折算**。
- 边界与诚实规则：
  - 无单价学员（total_hours=0 却有消课，或只有赠送课时）的消课课时单独汇总为 `unpriced_hours` 披露，收入记 0，**不许用全站平均价顶替**。
  - 试听课 is_trial=1 的 hours 为 0，自动不产生消课收入；但教师若实际授课，其成本在教师结算中自然体现（见 D4），符合"赠送/试听不产生收入、产生成本"。
  - 机构学员的课（classes.organization_id != 1，或 is_self_paid=0）**不走学员单价**：机构收入以 org_settlements 的 amount_due_cny（应收口径）为准，从直营消课收入中剔除，防止双算。直营/机构的划分字段以 classes.organization_id 与 is_self_paid 为准，阶段 2 开工前在代码中复核两字段的一致性口径后写死。

### D3 赠送课时：摊薄单价，不计现金

- payments 中 payment_method='gift' 的行：amount 不计入任何现金收入指标；其 hours 计入 total_hours 分母（经 students 计数器自然实现），从而摊薄混合单价。
- 收款看板中 gift 单独成行展示（笔数与课时数），不混入支付方式金额占比的分母。

### D4 教师课酬：PHP 按月锁定汇率折算

事实认定：teacher_payments 的 hourly_rate / total_amount 为菲律宾比索（费率 100/150、支付方式 gcash 为据），系统无币种字段，本设计不回填业务表，只在报表层折算。

- 新增报表专用表 `report_fx_rates`（见第三节迁移草案）：一行一个月份，存 PHP→CNY 乘数（如 0.1240）、来源、维护人、更新时间。
- 教师成本（CNY）= teacher_payments.total_amount × rate(结算 period_end 所在月)。已付（status='paid'）与待付（status='pending'）分开汇总；cancelled 不计。
- **锁定规则**：某月一旦被报表使用，其汇率只允许人工改（改即留痕更新 updated_at / updated_by），不随市场自动变动；历史月份报表数字因此稳定。
- 回退规则：查询月份无汇率记录时，取不晚于该月的最近一条并在响应中标 `rate_is_fallback: true`；**一条都没有时，财务接口的成本/毛利字段返回 null 并附 `fx_missing: true`，前端显示"汇率未设置"，严禁用 0 或估算值填充**。
- 展示规范（沿用评审版）：金额卡同时显示原始比索、折算人民币、汇率与汇率月份，如 `₱12,750 ≈ ¥1,581（汇率 0.1240，2026-10）`。
- 教师成本的直营/机构分摊：teacher_payments 不区分课源，v1 主口径做**全站毛利**（收入 = 直营消课收入估算 + 机构结算应收；成本 = 教师课酬折算总额）。如需直营毛利，按当月各教师 classes.hours 的直营/机构构成比例分摊其课酬，标注"按课时比例分摊（估算）"，作为附带指标，不作主数字。

### D5 退款：按发生期冲减，金额为估算并披露

- 系统没有退款金额记录：payments 有 amount>=0 约束、无退款行；退款动作体现在 hour_changes 的 adjust（type='adjust'、amount<0）与线下退款。
- v1 口径：报表设"课时调整"呈现——当期 adjust 正/负分开汇总；其中负向调整的估算金额 = |课时| × 该学员 blended_price，在发生月冲减课时负债，并从当期消课收入基数中提示性单列（不直接改消课收入数字，避免与 classes 实耗双算）。
- 注脚必须写明：「退款按发生期计入；系统未记录实际退款金额，此处为按混合单价的估算。」
- 阶段 2 前置核查项：通读 payments.js 与 hourChanges.js 路由，确认运营实际如何录退款（改 payments / 删行 / 只走 adjust）。若实际存在改收款记录的路径，收款看板天然反映，本条按核查结果在阶段 2 开工前修订一次。

### D6 试听转化：月度 cohort + 30 天窗口

- cohort = 学员首次试听课（classes.is_trial=1，取最早 date）所在自然月。
- 转化 = 该学员在首次试听日后 30 天内（含）出现首笔正课收款（payments.payment_method != 'gift' 且 hours > 0）。
- 输出按 cohort 月：试听人数、转化人数、转化率、平均转化天数（首试听→首收款）。
- 漏斗 v1 从试听起算，不含 leads 线索段（数据仅 3 条，无统计意义）；学员状态分布（active/inactive/graduated）单独呈现，不硬造漏斗状态机。

### 其他已定口径（阶段 0 结论直接采用）

- 流失预警：剩余课时 = total_hours − used_hours；≤3 紧迫、4–8 关注；未上课天数 = 今天 − MAX(classes.date)（仅 completed），status='active' 且剩余>0 且未上课 ≥14 天进预警名单（30 天为高危子集）。不用 students.last_class_at（维护不全）。
- 课时健康与负债：课时负债（CNY，估算）= Σ 活跃学员剩余课时 × blended_price；机构课时负债看 org_packages（amount_cny − paid_amount_cny 与未消耗课时）单独列，不并入直营负债。
- 反馈填报率：以 classes.fb_teacher_message 或 fb_vocab 非空为"已填反馈"（阶段 2 在代码中与现行反馈提交口径对齐后写死其一）；录像覆盖率 = fb_recording_status 非 'none' 的 completed 课占比。
- 五维评分趋势：classes.fb_score_* 五项按月均值；031 迁移较新，接口同时返回当月有评分课数 / 完课数（覆盖率），前端覆盖率低于 30% 的月份显示"数据积累中"。
- 时间参数：所有接口必传或默认 from_date / to_date（默认本月）；按月聚合一律用业务日期字段（classes.date / payments.date / teacher_payments.period_end）+ strftime，禁止用 created_at 做期间归属（UTC 偏差）。

## 二、接口清单（Hono，挂 /api/v1/reports，沿用现有 success 信封与 orgContext）

权限总则：super_admin 可查全部机构（org_id 参数可指定）；org_admin 强制锁定自身 orgId、且财务板块只返回本机构结算相关字段（教师课酬总额、直营毛利等全站字段后端直接不下发，不是前端隐藏）；teacher / parent 角色无报表权限。

| 接口 | 内容 |
|---|---|
| GET /reports/overview | 概览四组 KPI（现金流组 / 损益组 / 运营组，字段口径见各分接口），一次返回 |
| GET /reports/learning/summary | 课时健康分布、状态分布、教材分布与进度、五维均值与覆盖率、里程碑计数 |
| GET /reports/learning/risk-students | 流失预警名单（分页，含剩余课时、未上课天数、最后上课日期、混合单价估算的剩余价值） |
| GET /reports/financial/summary | 收款（按方式、gift 单列）、消课收入估算、课时负债、教师成本（双币 + fx 元信息）、机构应收/已收/待确认、全站毛利与分摊估算 |
| GET /reports/financial/trend | 近 N 月：充值、消课收入估算、教师成本 CNY、毛利 四线月度序列 |
| GET /reports/teaching/summary | 完课率/缺勤率/取消率、反馈填报率、录像覆盖率、固定教师率、试听 cohort 转化表 |
| GET /reports/teaching/workload | 教师负荷排行（节数、课时、25/50/60 分档，分页/排序） |
| GET /reports/fx-rates | 汇率列表（月份、rate、来源、更新时间/人） |
| PUT /reports/fx-rates/:month | 维护某月汇率（仅 super_admin，body: rate, source） |
| GET /reports/export | 按 type（learning/financial/teaching）+ 同筛选条件导出 CSV；财务 CSV 必须同时含 PHP 原额、汇率、CNY 折算三列 |

通用参数：from_date、to_date、org_id（仅 super_admin 有效）、page、page_size（明细默认 20、上限 50）。

## 三、数据库变更（仅一项，迁移编号接续现有序列）

```sql
-- 033_report_fx_rates.sql
-- 报表专用：PHP→CNY 月度参考汇率。只服务报表折算，不回填、不影响任何业务表。
CREATE TABLE IF NOT EXISTS report_fx_rates (
  month TEXT PRIMARY KEY,          -- 'YYYY-MM'，按教师结算 period_end 所在月取用
  rate REAL NOT NULL CHECK (rate > 0),  -- 1 PHP = rate CNY，如 0.1240
  source TEXT,                     -- 如 'Wise 实际汇款' / '月度平均' / 'XE 参考'
  updated_by TEXT,
  updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);
```

回滚：DROP TABLE report_fx_rates 即完全回滚，无业务影响。执行任何 D1 变更前先按既有惯例做全量导出备份。
